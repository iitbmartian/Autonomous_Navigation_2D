## Contribution Guidelines

### 🌿 1. Create a Branch
Never work directly on `main`.

```bash
git checkout main
git pull origin main
git checkout -b feature/<short-description>
```

### 🛠️ 2. Develop & Commit
Make your changes, test them, and use **Gitmoji** for every commit.

Examples:
- ✨ `✨ Add LiDAR localization`
- 🐛 `🐛 Fix TF issue`
- ♻️ `♻️ Refactor navigation node`
- 📝 `📝 Update documentation`

### 📤 3. Push & Open a PR
Push your branch and open a Pull Request to `main`.

```bash
git push origin feature/<short-description>
```

PR titles should also use an appropriate **Gitmoji** and clearly describe the change.

### 👀 4. Code Review
Get your code reviewed by a team member. Address review comments before merging.

### ✅ 5. Merge
Only approved PRs should be merged into `main`.

**Keep `main` stable, tested, and deployable.**
